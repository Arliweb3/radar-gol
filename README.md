Football games listed on Polymarket in the next 48 hours, with stats-based probabilities for **Over 1.5 total goals** and **Over 0.5 first-half goals** (no betting odds used). Updated automatically every morning.

Data: Polymarket, ESPN, FotMob, Flashscore. Stats are probabilities, not guarantees.
